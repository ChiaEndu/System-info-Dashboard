# DASHBOARD

## About
the system info dashboard is an application built with bash that helps provide system info when requested by the user

## features
* 1 system info
 provides info on 
- current user
- host
- date and time
* 2 up time
tells the user how long the computer has been on 
* 3 memory usage 
provides information on memory usage 
* 4 disk usage 
provides information about the disk like;
total disks space,
total used 
and free storage on disk
* 5 running processes 
this section provides the total number of running processes and the top 5 memory consuming processes
